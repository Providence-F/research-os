# 假设账本（v0.9 schema）

> v0.9 升级：融入 ljg-think"追本之箭"方法论。
> 每条假设不只记录"是什么"，还要记录"为什么这么假设"的层层追问，
> 直到不可再分（root_cause）。假设修订时必须填"为什么改"——
> 这本身就是 ljg-think 的核心：不停追问为什么。

## schema 说明

每条假设结构：

```json
{
  "hypothesis_id": "H001",
  "statement": "我假设...",
  "confidence": "high|medium|low",
  "status": "open|confirmed|revised|rejected",
  "drill_down": [
    "为什么这么假设？因为...",
    "为什么是这个原因？因为...",
    "为什么...？（不可再分，到此为止）"
  ],
  "root_cause": "追问到底的根因，一句话",
  "evidence_supporting": ["E001", "E003"],
  "evidence_refuting": ["E005"],
  "revision_log": [
    {
      "from": "high",
      "to": "medium",
      "reason": "为什么改？因为 E005 显示...",
      "timestamp": "2026-07-03"
    }
  ]
}
```
