# 主题路由规则

> 不要靠无限增加完整模板来接住新主题。先路由，再组合研究模块和视图模块。

## 1. 三层架构

```text
Topic Router -> Research Modules -> View Modules
```

- Topic Router：判断任务是什么。
- Research Modules：决定需要哪些分析、证据、反方和状态文件。
- View Modules：决定 HTML 用卡片、Tab、筛选、矩阵还是纯正文。

## 2. research_mode

| research_mode | 适用场景 | 核心问题 |
|---|---|---|
| evidence_intelligence | 事实核验、行业资料、普通主题研究 | 哪些事实可靠？ |
| thinking_decision | 选题、职业选择、作品集方向、项目优先级 | 这件事值不值得做？怎么投入？ |
| opportunity_map | 公司清单、展商地图、岗位地图、候选池 | 哪些对象优先？如何筛选？ |
| product_teardown | 产品、竞品、机制拆解 | 产品怎么工作？为什么有效或无效？ |
| user_voice | 用户访谈、评论、需求洞察 | 用户真实表达什么？ |
| career_strategy | JD、公司、投递、求职策略 | 如何把个人背景转成机会？ |

## 3. view_type

| view_type | 适用输出 | 必需视觉模块 |
|---|---|---|
| narrative_report | 短报告、低交互需求 | full_report, appendix_fold |
| card_dashboard | 多对象快速浏览 | summary_cards, object_cards |
| ranked_map | 排名 / 地图 / 候选池 | object_cards, filters, detail_modal, filterable_table |
| comparison_matrix | 横向比较决策 | comparison_matrix |
| decision_board | 投入策略 / 选项决策 | hero, summary_cards, object_cards, strategy_tabs |
| product_teardown_view | 产品机制拆解 | object_cards, focus_tabs, comparison_matrix |

## 4. 默认路由

| research_type | 默认 research_mode | 默认 view_type |
|---|---|---|
| product | product_teardown | product_teardown_view |
| competitor | product_teardown | product_teardown_view |
| user-research | user_voice | card_dashboard |
| portfolio | thinking_decision | decision_board |
| company-jd | career_strategy | decision_board |
| industry | opportunity_map | ranked_map |
| topic | evidence_intelligence | narrative_report |
| mixed | evidence_intelligence | narrative_report |

## 5. 关键词覆盖

项目名中出现这些词时，优先覆盖默认路由：

- 选题、导师、毕业论文、职业、求职、作品集、要不要、是否值得 -> `thinking_decision / decision_board`
- 地图、榜单、候选池、展商、公司清单、秋招、投递、岗位 -> `opportunity_map / ranked_map`
- 产品、机制、拆解、竞品、体验、增长、商业模式 -> `product_teardown / product_teardown_view`
- 用户、访谈、评论、需求、痛点、原声 -> `user_voice / card_dashboard`

## 6. 人工覆盖

`research_state.json` 可以手动覆盖：

```json
{
  "research_mode": "thinking_decision",
  "view_type": "decision_board",
  "visual_modules": ["hero", "summary_cards", "object_cards", "strategy_tabs", "full_report", "appendix_fold"]
}
```

## 7. 禁止事项

- 不要因为一个新主题就复制一整套最终报告模板。
- 不要把证据矩阵当作读者报告。
- 不要让 R2/R3 非叙事项目只生成长滚动正文。
- 不要把视图模型写成第二份正文。
