## 来源独立性规则

> 多个搜索结果不等于多个独立来源。

| 标记 | 定义 | 处理 |
|---|---|---|
| 独立 | 来源来自不同机构/不同原始发布者，且不是互相转载 | 可支持 B 级或更高 |
| 同源传抄 | 多个页面都引用同一篇 PR 稿、官网、招聘 JD、媒体通稿 | 按单源处理，默认 C 级 |
| 未知 | 搜索汇总没有暴露原始 URL，无法判断来源是否独立 | 默认 C 级 |

**硬规则**：

- MiMo / Perplexity / ChatGPT / 搜索摘要类结果默认视为 C 级线索。
- 只有拿到 ≥2 个可访问、可核验、相互独立的原始 URL，才能升为 B 级。
- 搜索汇总可以帮助找方向，但不能直接当成事实。
- 如果原始页面 SSR 不可读、登录墙不可读、验证码不可过，必须标 `待验证`，不能靠摘要补全。

## 证据等级说明

| 等级 | 定义 | 可支持的结论 | 禁止事项 |
|---|---|---|---|
| A | 官方 / 原文 / 完整可核验 | 可以作为核心事实 | 不需要推断补全 |
| B | ≥2 个独立原始来源一致，或可信权威材料 | 可以支持中等强度判断 | 不写成绝对事实 |
| C | 单源 / 摘要 / 列表 / 搜索汇总 / 来源独立性未知 | 只能作为线索 | 不能逐句拆解，不能支撑强结论 |
| D | 合理推断 | 只能标注为推断 | 不能伪装成事实 |
| E | 待验证 | 进入待验证清单 | 不进入结论主体 |
| F | 误匹配 / 不可用 | 剔除 | 不再引用 |

## freshness 字段

| 标记 | 含义 |
|---|---|
| fresh | 一年内，且无更新版本 |
| dated | 1-3 年，需标注是否仍有效 |
| stale | 3 年以上，只作历史参考 |
| snapshot | 抓取时点的快照，可能已变 |
