# Research OS Archive

此目录存放历史版本归档。**不要参考这里的文件作为当前规范。**

当前规范在：
- `templates/` 目录
- `*.py` 文件（Python 引擎，根目录）

## 归档原因

这些文件是 Research OS 从 v0.1 演进到 v1.1 过程中的历史快照。保留是为了：

1. **版本回退**：如果新版本引入问题，可以从归档恢复
2. **审计**：查看某个功能是怎么演化的
3. **学习**：理解系统设计决策的变迁

## 目录结构

```
archive/
├── v0.1/    # 最早的入口文档（Dify 时代）
├── v0.7/    # 引入 goal_ledger 和 iteration_log 之前

```
